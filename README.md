# DJI Osmo Action 4 · 交互式 3D 拆解可视化

纯 **Three.js + HTML + CSS + JavaScript** 实现的运动相机交互式拆解页面。
**不依赖任何外部 3D 模型文件**：机身、镜头、CMOS、主板、电池、双屏、按键、接口仓门、磁吸底座
全部由代码用基础图元（Box / Cylinder / Torus / Sphere / Shape 挤出圆角盒）程序化生成；
环境反射贴图与屏幕取景界面由 `<canvas>` 实时绘制生成。

## 打开方式

直接双击 `index.html` 即可（大量已本地化为普通 `<script>`，可在 `file://` 下运行，无需本地服务器、无需联网）。

```
D:\app\dji-action4-3d\
├─ index.html              页面入口
├─ css\style.css           深色科技风界面样式
├─ js\parts-data.js        10 个部件的名称 / 参数 / 说明 / 拆解位移
├─ js\build-model.js       程序化建模（几何体、材质、Canvas 贴图、描边）
├─ js\main.js              场景、灯光、后期辉光、拾取、动画、面板联动
├─ lib\                    Three.js r147 与示例模块（已离线内置）
└─ preview\                渲染预览图
```

## 交互功能

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 自由旋转视角（OrbitControls，带阻尼） |
| 滚轮 / 双指 | 缩放（拆解时相机会自动后撤，保证全部件在画面内） |
| 右键拖动 | 平移 |
| 单击部件 | 该部件单独拆出 + 发光描边 + 其余部件压暗 + 右侧显示规格详情 |
| 再次单击 / `Esc` | 取消选中，部件归位 |
| 空格 或 「拆解全部」 | 10 个部件沿各自轴向分离，外壳渐变为半透明以露出内部 |
| 「自动旋转」 | 模型缓慢自转 |
| 「显示标注」/ `L` | 部件名称 + 关键参数浮动标注开关 |
| `R` / 「重置视角」 | 恢复初始机位与装配状态 |

## 页面构成

- **部件清单**：10 个部件（机身外壳 / 前镜头模组 / CMOS / 主控板 / 电池 / 后置触摸屏 / 前置显示屏 / 顶部按键与麦克风 / 接口仓门 / 磁吸底座），可点击选中，与 3D 模型双向联动。
- **整机规格**：传感器、镜头、视频、色彩、增稳、电池、屏幕、防护、重量。
- **部件详情**：序号、中英文名、所属分组、4 项规格、作用说明。
- **操作引导**：顶栏按钮 + 底部快捷键提示条 + 概览面板内的操作说明。

## 已实现的视觉 / 技术要点

- 深色科技背景：程序化等距柱状环境贴图（PMREM）、渐变雾、网格地面、三层光环、虚线刻度环、星尘粒子、地面光晕，以及 CSS 暗角与扫描线。
- 拆解高亮：部件选中/悬停时材质自发光增强 + 背面克隆描边，其余部件整体压暗；解算采用逐部件独立材质实例，互不干扰。
- 后期处理：EffectComposer + UnrealBloomPass 辉光（阈值 0.9，仅屏幕 HUD 与高光溢出发光）。
- 屏幕内容：后置 2.25" 与前置 1.4" 的取景界面（构图线、对焦框、REC 指示、码率/电量/增稳信息）均为 Canvas 实时绘制。
- 参数取自 Osmo Action 4 公开规格：70.5 × 44.2 × 32.8 mm、145 g、1/1.3" CMOS（等效 2.4 μm）、155° / f2.8、4K120、10-bit D-Log M、RockSteady 3.0、1770 mAh / 最长 160 分钟、裸机 18 m 防水。

## 兼容性

- 需要支持 WebGL 的桌面浏览器（Chrome / Edge / Firefox 均可）。加载失败时会显示中文回退提示而不是白屏。
- 页面暴露 `window.__DJI_DEBUG`（场景 / 相机 / 部件状态）便于自动化校验，不影响正常使用。
